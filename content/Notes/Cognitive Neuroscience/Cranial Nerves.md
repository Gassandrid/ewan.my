- originate from [[Brainstem]] and innervate muscles of the head, neck, face, tongue, larunx, pharunc, and glands
- important for sensory [[Perception]], speech, motor functions
- 12 pairs
- numbered with roman numberals ( CN I - CN XII )
- Each has a special function ( no way )

| Number  | Name                                   | Major motor function                             | Major sensory function       | Mnemonic  |
| ------- | -------------------------------------- | ------------------------------------------------ | ---------------------------- | --------- |
| CN I    | [[Olfactory Nerve]]                    |                                                  | Smell                        | On        |
| CN II   | [[Optic Nerve]]                        |                                                  | Vision                       | Old       |
| CN III  | [[Oculomotor Nerve]]                   | Eye movement                                     |                              | Olympus's |
| CN IV   | [[Trochlear Nerve]]                    | Eye movement                                     |                              | Topmost   |
| CN V    | [[Trigeminal Nerve]]                   | Chewing                                          | Sensation: face, eyes, mouth | Top       |
| CN VI   | [[Abducens Nerve]]                     | Eye movement                                     |                              | A         |
| CN VII  | [[Facial Nerve]]                       | Facial expression; secretion of saliva and tears | Taste                        | Finn      |
| CN VIII | [[Vestibulocochlear Nerve]] (acoustic) |                                                  | Equilibrium, hearing         | And       |
| CN IX   | [[Glossopharyngeal Nerve]]             | Swallowing                                       | Taste                        | German    |
| CN X    | [[Vagus Nerve]]                        | Speaking, swallowing                             | Sensation: thorax, abdomen   | Viewed    |
| CN XI   | [[Accessory Nerve]]                    | Head movement, shoulder elevation                |                              | A         |
| CN XII  | [[Hypoglossal Nerve]]                  | Tongue movement                                  |                              | Hop       |
